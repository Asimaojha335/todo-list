# To-Do List

A task manager built with plain HTML, CSS and JavaScript.

- Add tasks with a priority (low, medium, high) and an optional due date
- Mark tasks done, edit them (double-click or the pencil), delete with undo
- Filters (All, Active, Done), search, and a progress bar
- Overdue tasks are highlighted; tasks are sorted by status, priority and due date
- Saved in the browser (localStorage), light and dark theme, responsive

Open `index.html` in a browser. No build step is needed.
